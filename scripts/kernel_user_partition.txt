# Kernel / user-space partition of the SOF sources, used by
# scripts/check_kernel_includes.py.
#
# Kernel code runs in Zephyr supervisor mode: hardware and MMIO access,
# interrupts, thread and memory domain creation, cache/MMU, power and
# clock management, DMA and DAI driver internals, IDC, LLEXT loading and
# system call verification. User-space code is everything else and must
# only use plain C, system-call backed Zephyr APIs and SOF system calls,
# whether or not a given configuration actually runs it in user mode.
#
# Patterns are fnmatch globs relative to the SOF top directory, except
# [zephyr-kernel-headers] which is relative to ZEPHYR_BASE. "*" also
# matches "/".
